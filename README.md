# Explainable-Skin-Lesion-Classification-Framework

# CNN-Based Image Classification Project

## Project Title
Explainable Skin Lesion Classification Framework Using CNN and Transfer Learning

## Dataset
Dataset used from Kaggle: https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000

## Project Description
This project uses CNN-based image classification to classify skin lesion images into different categories. The work includes preprocessing, augmentation, CNN training, transfer learning comparison, evaluation, confusion matrix, accuracy/loss curves, and Grad-CAM visualization.

## Models Used
- Custom CNN
- Transfer Learning Model

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## How to Run
1. Open the Kaggle Notebook.
2. Add the dataset.
3. Run all cells from top to bottom.
4. Output figures and tables will be saved automatically.
